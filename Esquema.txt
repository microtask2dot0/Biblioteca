🟢 Paso 2 — ¿Qué es SQLite?

SQLite es una base de datos que vive en un archivo.

Por ejemplo, nuestra aplicación terminará teniendo:

mi_biblioteca/
├── biblioteca.py
└── biblioteca.db

biblioteca.db será nuestra base de datos.

Una de las ventajas de SQLite para este proyecto es que no necesitas instalar un servidor de bases de datos.

Python además incluye el módulo sqlite3, así que para empezar no necesitamos instalar ninguna biblioteca externa.

🧠 ¿Qué acabamos de hacer?

Esta línea:

le dice a Python:

"Quiero utilizar SQLite."

Esta:

conexion = sqlite3.connect("biblioteca.db")

hace algo muy interesante.

Le dice:

"Conéctate a biblioteca.db."

Y finalmente:

cierra la conexión con la base de datos.

Primero vamos a crear una función para mostrar los elementos con sus IDs

En items.py añade:

def obtener_items():
    conexion = conectar()
    cursor = conexion.cursor()


    cursor.execute("""
        SELECT id, titulo, tipo
        FROM items
        ORDER BY titulo
    """)


    items = cursor.fetchall()


    conexion.close()


    return items

Esta función es diferente de mostrar_items().

mostrar_items() imprime los resultados.

obtener_items() los devuelve para que otra función pueda utilizarlos.

Por ejemplo:

items = obtener_items()

y entonces items podría contener:

[
    (1, "Abbey Road", "música"),
    (2, "Blade Runner", "película"),
    (3, "Dune", "libro")
]
🟢 Paso 41 — Hacer lo mismo con los dispositivos

En dispositivos.py:

def obtener_dispositivos():
    conexion = conectar()
    cursor = conexion.cursor()


    cursor.execute("""
        SELECT id, nombre, tipo
        FROM dispositivos
        ORDER BY nombre
    """)


    dispositivos = cursor.fetchall()


    conexion.close()


    return dispositivos

Ahora tenemos:

obtener_items()

Ahora podemos modificar ubicaciones.py.

Primero importamos las funciones:

from database import conectar

Y hacemos que añadir_ubicacion() muestre los elementos:

def añadir_ubicacion():
    items = obtener_items()


    if not items:
        print("No hay elementos en la biblioteca.")
        return


    print()
    print("¿Qué elemento quieres ubicar?")


    for item in items:
        print(f"{item[0]}. {item[1]} ({item[2]})")


    item_id = input("Selecciona el ID: ")

Después hacemos lo mismo con los dispositivos:

    dispositivos = obtener_dispositivos()


    if not dispositivos:
        print("No hay dispositivos registrados.")
        return


    print()
    print("¿En qué dispositivo está?")


    for dispositivo in dispositivos:
        print(f"{dispositivo[0]}. {dispositivo[1]} ({dispositivo[2]})")


    dispositivo_id = input("Selecciona el ID: ")


    ruta = input("Ruta o ubicación: ")

Y finalmente guardamos la relación:

    conexion = conectar()

        INSERT INTO ubicaciones (
            item_id,
